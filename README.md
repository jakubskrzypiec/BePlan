# BEPLAN — Design + Build

Kompletna statyczna strona BEPLAN, wersja v12 (szare niebo, sprzed zmiany kolorystyki).

Źródła HTML, CSS, JavaScript, zdjęcia, logotypy oraz dane realizacji znajdują się w `dist/`. Strona nie wymaga instalacji zależności ani kompilacji.

## Podgląd lokalny

Uruchom dowolny serwer HTTP w katalogu `dist`, np. `python -m http.server 8000`, a następnie otwórz http://localhost:8000.

## Publikacja

Workflow GitHub Actions publikuje katalog `dist` w GitHub Pages. W ustawieniach repozytorium wybierz **Pages → Source → GitHub Actions**.

Formularz kontaktowy przygotowuje wiadomość w programie pocztowym odwiedzającego; nie ma backendu wysyłającego e-maile. Zdjęcia hero i przerywnika są ilustracjami koncepcyjnymi AI. Zdjęcia realizacji i logotypy pochodzą z materiałów BEPLAN.
